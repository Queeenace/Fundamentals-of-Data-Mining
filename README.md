# Частые наборы покупок: Apriori

Поиск всех частых наборов с поддержкой, два варианта сортировки и эксперименты на `baskets.csv`.
Python 3.10+; сам алгоритм и эксперименты используют только стандартную библиотеку.

## Запуск

```bash
python3 apriori.py data/baskets.csv --support 3% --order support --output results/example.json
python3 apriori.py data/baskets.csv --support 0.03 --order lex
python3 -m unittest discover -s tests -v
python3 experiments.py
```

`--support`: доля (0.03) или процент (3%). Диапазон (0, 1]. `--order support`:
поддержка по убыванию, при равенстве лексикографически. `--order lex`: сравнение
кортежей названий по Unicode, без локали. Названия внутри наборов отсортированы.
Выход JSON: `items`, `length`, `count` (число корзин), `support` (доля корзин).

## Данные

Предоставленный пользователем CSV сохранён байт-в-байт в `data/baskets.csv`.
7 501 строка без заголовка, Windows-1251, запятая; каждая строка - корзина.
115 товаров. 39 повторных вхождений внутри корзин удаляются при чтении.
Одинаковые корзины в разных строках сохраняются. Пустые поля и строки игнорируются,
пробелы по краям удаляются. Автоопределение пробует UTF-8, затем Windows-1251;
для другого файла можно явно передать `--encoding`.

## Метод

Apriori выполняет поуровневое объединение частых наборов с общим префиксом и
отсечение кандидатов с нечастыми подмножествами. Поддержка считается через
пересечение битовых масок транзакций и `int.bit_count()`. Порог переводится
в целое число корзин как `ceil(s*N)` с помощью Decimal.

## Эксперименты и результаты

`results/experiments.json`: параметры среды, SHA-256 данных, сводка и число кандидатов.
`results/timings.csv`: 75 сырых измерений в мс. Для каждого порога: один прогрев,
15 измерений; порядок перемешан с seed=42. Измерение включает построение масок и
поиск, исключает чтение CSV, сортировку, экспорт и графики. Используется медиана,
на рисунке также минимум и максимум (это не доверительный интервал).

| Поддержка | Одиночные | Пары | Тройки | Всего |
|---|---:|---:|---:|---:|
| 1% | 74 | 170 | 17 | 261 |
| 3% | 36 | 19 | 0 | 55 |
| 5% | 25 | 3 | 0 | 28 |
| 10% | 7 | 0 | 0 | 7 |
| 15% | 5 | 0 | 0 | 5 |

Полные результаты каждого порога сохранены в обеих сортировках:
`results/itemsets_XX_support.json` и `results/itemsets_XX_lex.json`.
Независимая проверка считает комбинации корзин горизонтальным перебором до длины 3;
тесты также сравнивают алгоритм с полным перебором на случайных малых данных.

## PDF и рисунки

```bash
python3 -m pip install -r requirements.txt
python3 build_report.py --repo-url https://github.com/OWNER/REPOSITORY
```

Для кириллицы нужны DejaVuSans.ttf и DejaVuSans-Bold.ttf: установите шрифты
DejaVu Sans или передайте `--font-dir /path/to/fonts`.
Отчёт: `output/pdf/apriori_report.pdf`; векторные рисунки: `figures/`.
При запуске без `--repo-url` PDF содержит локальную ссылку и явное предупреждение,
что публикация ещё не завершена. Перед сдачей нужно пересобрать его с реальным URL.

Источник алгоритма: [Agrawal, Srikant, VLDB 1994](https://rsrikant.com/papers/vldb94.pdf).
