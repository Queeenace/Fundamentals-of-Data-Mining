# Ассоциативные правила: Apriori

Продолжение первой лабораторной работы. Программа строит ассоциативные правила
по частым наборам, указывает поддержку и достоверность каждого правила, а также
проводит эксперименты с разными порогами достоверности.

## Запуск

```bash
python3 apriori.py data/baskets.csv --support 1% --confidence 40% --order support
python3 apriori.py data/baskets.csv --support 0.01 --confidence 0.4 --order lex --format json
python3 -m unittest discover -s tests -v
python3 rule_experiments.py
```

`--support` и `--confidence` принимают долю или процент. `--order support`
сортирует правила по убыванию поддержки, затем достоверности. `--order lex`
сортирует антецеденты и консеквенты лексикографически. По умолчанию выводится
читаемый список `антецедент → консеквент`. Параметр `--format json` включает
вывод в JSON, а `--max-rule-length 7` ограничивает суммарное число объектов
в обеих частях правила.

## Данные и метод

Исходный файл сохранён в `data/baskets.csv`. В нём 7 501 покупательская корзина
и 115 разных товаров. Программа распознаёт UTF-8 и Windows-1251, удаляет повторы
товара внутри одной корзины и сохраняет одинаковые корзины в разных строках.

Сначала Apriori находит частые наборы при фиксированной поддержке 1%. Затем из
каждого набора длиной не менее двух перебираются непустые антецеденты. Остальные
объекты образуют консеквент. Достоверность вычисляется как отношение поддержки
всего набора к поддержке антецедента. Правило сохраняется, если достоверность
не ниже заданного порога.

## Эксперименты и результаты

`rule_experiments.py` меняет порог достоверности от 20% до 50% с шагом 5%.
Для каждого значения выполняются один прогрев и 100 измерений поиска и сортировки
правил. Частые наборы рассчитываются до измерений, поскольку они не зависят от
порога достоверности.

Сводка хранится в `results/rule_experiments.json`, отдельные измерения находятся
в `results/rule_timings.csv`. Полные списки правил в двух вариантах сортировки
сохранены в файлах `results/rules_XX_support.json` и `results/rules_XX_lex.json`.
Для содержательного анализа выбраны 19 правил с достоверностью от 40%.

Диаграммы создаются методом `save_rule_charts` из `plots.py`:

- `figures/rule_runtime.svg` показывает время поиска правил;
- `figures/rule_count.svg` показывает общее количество правил.
