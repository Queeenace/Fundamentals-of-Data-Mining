# Лабораторная работа 4. Ансамблевая классификация

Программа строит случайный лес на данных Census Income из [третьей работы](../3/).
Исходный набор и общий код подготовки признаков лежат в `../3/data/` и
`../3/decision_tree.py`. Для воспроизведения нужен весь репозиторий.

## Запуск

Из корня репозитория:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r 4/requirements.txt
.venv/bin/python 4/ensemble.py --technique random_forest --n-estimators 100 --train-share 0.8 --output 4/results/example.json
.venv/bin/python -m unittest discover -s 4/tests -v
.venv/bin/python 4/experiments.py
```

Параметры `--max-depth`, `--min-leaf`, `--max-features` задают устройство леса.
Параметр `--data` позволяет подать другой файл того же формата. Реализованная
ансамблевая техника выбирается параметром `--technique random_forest`.

## Эксперимент

Для 50, 60, 70, 80, 90 и 100 деревьев используется одна стратифицированная
выборка: 80% для обучения и 20% для теста, seed=42. Для леса зафиксированы
глубина 12, минимум 10 записей в листе, выбор `sqrt` признаков и критерий
Джини. Положительный класс: доход `>50K`.

Одиночное дерево для сравнения взято из опыта 80% / 20% третьей работы.
Тестовые записи и кодирование признаков совпадают. Настройки дерева и леса
различаются, что явно указано в отчёте.

Полные результаты и важности признаков находятся в `results/summary.json`.
Диаграмма четырёх показателей качества находится в
`figures/forest_quality.png`. Готовый
[PDF-отчёт](output/pdf/random_forest_report.pdf) содержит задание, ссылку на
репозиторий, диаграмму и объяснение результатов. Основной текст набран
шрифтом Times New Roman размером 14 пунктов.
