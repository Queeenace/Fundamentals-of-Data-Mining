# Лабораторная работа 5. Разделительная кластеризация

Программа выполняет k-Means и k-Medoids на наборе [customers.csv](data/customers.csv). Описание признаков находится в [customers_description.txt](data/customers_description.txt). Для анализа используются возраст, образование, стаж, доход, долг по карте, прочие долги и отношение долга к доходу. Идентификаторы и признак `Defaulted` исключены: у последнего отсутствуют 150 значений. Перед кластеризацией признаки стандартизируются.

```bash
python 5/cluster.py --data 5/data/customers.csv --algorithm kmeans --k 5 --noise 0.03 --output 5/results/example.csv
python 5/cluster.py --data 5/data/customers.csv --algorithm kmedoids --k 5 --output 5/results/example_medoids.csv
python 5/experiments.py
```

`--noise` задаёт долю случайно выбранных клиентов от 0 до 1. Их признаки меняются случайными величинами с фиксированным зерном генератора. На выходе программа показывает среднее евклидово расстояние до назначенного центра или медоида, а также собственную целевую функцию алгоритма. CSV сохраняет исходные координаты после внесения шума и номер кластера для каждого клиента.

Эксперименты охватывают k от 3 до 9 и шум 0%, 1%, 3%, 5%, 10%. [Таблица результатов](results/experiments.csv), [зависимость ошибки от k](figures/error_by_k_and_noise.png), [проекция кластеров при k=5](figures/clusters_k5_by_noise.png) и [отчёт PDF](output/pdf/partition_clustering_report.pdf). Цвета на разных панелях обозначают номера кластеров внутри соответствующего запуска, поэтому их нельзя трактовать как неизменные категории клиентов.
